# Java Pomůcka

Rychlá příručka a přehled klíčových konceptů v jazyce Java určená pro studium, opakování a přípravu na zkoušky.

## 📌 Obsah

- **Základní syntaxe & Datové typy**: Primitivní typy, proměnné, podmínky a cykly.
- **OOP (Objektově orientované programování)**: Třídy, objekty, dědičnost, rozhraní (interfaces) a polymorfismus.
- **Kolekce (Collections)**: Použití `List`, `Set`, `Map` a manipulace s nimi.
- **Práce s výjimkami**: `try-catch-finally`, vlastní výjimky.
- **Vstup a výstup (I/O)**: Čtení a zápis do souborů.

## 🚀 Jak začít

1. Klonujte repozitář:
   ```git clone [https://github.com/stepprok/java-pomucka.git](https://github.com/stepprok/java-pomucka.git)```
   
Otevřete projekt v libovolném IDE (IntelliJ IDEA, Eclipse, VS Code).

Spusťte požadované ukázky nebo příklady.
